三年课程体系

公共基础课 + 专业核心课 + 集中实践环节三层结构 · 总学分 72 · 实践占比 ≥ 50%

第一学年 基础筑牢 · 建立计算机思维
建议 60% 时间用于编程练习

🎯 学年能力目标

  • •理解计算机硬件/软件/网络基本原理
  • •熟练使用 Python 基础语法，能写简单数据处理脚本
  • •掌握 Git + GitHub 版本控制，会搭建开发环境
  • •具备使用 Excel 进行数据整理的基础能力

📚 核心课程（12 门）

  • ▸ 高等数学（4 学分）
  • ▸ 大学英语（4 学分）
  • ▸ 计算机基础（2 学分）
  • ▸ Python 程序设计（6 学分）
  • ▸ 计算机网络（4 学分）
  • ▸ Linux 操作系统基础（3 学分）
  • ▸ 思想政治（4 学分）+ 体育（2 学分）

🛠 实训任务

项目 1：学生成绩管理系统

用 Python + 文件存储实现增删改查

项目 2：豆瓣电影 Top250 爬虫

Requests + BeautifulSoup，输出 CSV

✅ 技能证书

计算机二级 Python

核心学年 · 大数据技术栈入门
第二学年 专业进阶 · 深入大数据核心技术
建议 40% 时间用于集群搭建与调优

🎯 学年能力目标

  • •能独立安装 MySQL，熟练编写 SQL 多表查询与优化
  • •独立搭建 Hadoop（HDFS + YARN + MapReduce）集群
  • •掌握 Spark 核心 API（RDD + DataFrame + SQL）
  • •能使用 DataX/Kettle 完成数据迁移和 ETL

📚 核心课程（14 门）

  • ▸ Java 程序设计（4 学分）
  • ▸ MySQL 数据库原理与 SQL 进阶（6 学分）
  • ▸ Hadoop 大数据平台部署与运维（6 学分）
  • ▸ Spark 分布式数据处理（5 学分）
  • ▸ Flink 实时流式计算（4 学分）
  • ▸ 数据仓库与数据挖掘导论（4 学分）
  • ▸ 概率论与数理统计（3 学分）

🛠 实训任务

项目 1：电商数据仓库建模

Kimball 维度建模 + Hive 表设计

项目 2：Spark 用户行为分析

Spark SQL + DataFrame + MySQL 输出

✅ 技能证书

华为 HCIA 大数据 / 阿里云 ACP

第三学年 实战冲刺 · 综合项目 + 岗位实习
50% 时间用于企业实习 + 毕业设计

🎯 学年能力目标

  • •熟练使用 ECharts/Tableau/FineBI 构建交互式 BI 看板
  • •具备前端基础（HTML/CSS/JS），能将数据嵌入 Web 页面
  • •完成 6 个月企业实习，适应职场环境
  • •独立完成毕业设计项目（如本网站）

📚 核心课程（10 门 + 实习）

  • ▸ 数据可视化（ECharts + Tableau）（5 学分）
  • ▸ ETL 工具与数据治理（DataX / Airflow）（4 学分）
  • ▸ 机器学习基础（Scikit-learn 实战）（4 学分）
  • ▸ Web 前端开发基础（HTML/CSS/JS）（3 学分）
  • ▸ 大数据综合项目实训（6 学分）
  • ▸ 岗位实习（6 个月，8 学分）
  • ▸ 毕业设计（6 学分）

🛠 实训任务

项目 1：企业级 BI 看板搭建

ECharts + Spring Boot + MySQL

项目 2：本网站即为真实成果

Web 前端 + ECharts + 数据清洗综合

✅ 毕业要求

实习鉴定合格 + 毕业设计答辩通过

课程重要度雷达图：行业需求 vs 课程覆盖

蓝色区域 = 行业实际岗位的重要度评分（满分 10），橙色区域 = 学校当前课程的开设覆盖度评分。两区域的"间隙"即为课程改进方向。

💡 关键洞察：Python 和数据库两方面课程覆盖度高，但 Hadoop/Spark/Flink 三门大数据核心课的覆盖度明显低于行业需求，建议强化实训环节。
