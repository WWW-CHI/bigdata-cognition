第一学年 · 基础夯实阶段 2024.09 - 2025.07

编程与数据基础入门

📖 主要学习内容

高等数学、计算机基础、Python 基础、Office 数据处理、网页基础（HTML/CSS）。这一年的目标是建立逻辑思维，掌握基础编程，学会简单的数据录入与整理，适应计算机类专业的学习方式。

🎯 技能收获

Python 基础语法 Office 数据处理 网页基础 HTML/CSS 计算机基础操作

💭 个人感悟：刚开始学编程很不适应，循环和函数经常绕晕，只能照着例题一遍遍改。第一学期用 Python 把一份几百行的成绩表按条件整理好，虽然只是基础练习，但比光看书有用得多。这一年最大的收获是清楚了自己"不会什么"，知道该按什么顺序去补。

大二
第二学年 · 专业核心阶段 2025.09 - 2026.07

数据库、大数据平台与数据处理

📖 主要学习内容

数据库原理与 MySQL、Linux 基础、Hadoop 基础、数据采集、数据清洗、数据分析。这一年重点练习数据表的搭建、简单的数据筛选和批量处理，理解大数据平台的基础使用方法。

🎯 技能收获

MySQL 数据表搭建 SQL 查询与筛选 Linux 常用命令 Hadoop 平台基础使用 数据批量处理

💭 个人感悟：大二课程明显变多，第一次感到吃力。MySQL 建表常因为字段类型选错返工，Linux 命令全靠笔记一条条记，Hadoop 第一次跑通示例程序用了好几天。后来慢慢学会报错先看日志，把常用命令和踩过的坑记在本子上，实操经验就是这样一点点攒下来的。也是这一年对大数据岗位有了实际的认识：岗位里大量工作是数据采集、清洗、统计这些基础活，不像入学前想的那么"高大上"。

第三学年 · 综合实训阶段 2026.09 - 2027.06

可视化与综合项目实战

📖 主要学习内容

Spark 基础、数据可视化、ECharts 图表开发、综合项目实战。把前两年学的编程、数据库、数据处理、可视化知识整合起来，独立完成一个小型大数据综合项目——也就是本网站，锻炼从获取数据、处理数据到可视化展示的完整能力。

🎯 技能收获

Spark 基础 ECharts 图表开发 数据可视化 综合项目整合

💭 个人感悟：综合实训把前两年的内容串了起来：数据从公开数据集获取，整理后存进数据库，统计用 SQL 或 Spark 完成，最后用 ECharts 画成图表。做本网站的过程并不顺利，图表数据怎么组织、页面布局怎么调，都是边查资料边改出来的。毕业后我打算继续深耕数据处理与可视化方向，把这条流程走得更熟练。

📋 项目总结

一、项目定位

「大数据技术专科专业 · 三年学习成果综合展示平台」

本网站不再是简单的科普介绍页，而是一个贯穿三年学习轨迹的成果展示平台。它以"我学了什么 → 我用在了哪里 → 我做出了什么"的第一人称叙事， 系统性地将专业介绍、课程体系、就业方向、学习路线、调研可视化五个板块串联起来， 是数据处理流程和可视化表达技术在一个真实场景下的完整落地演示。

三、技术实现清单

✓ 多文件静态架构

7 个独立 HTML 文件 + assets 目录，零后端依赖，双击打开即可运行

✓ 4 个 ECharts 图表

雷达图（课程覆盖）/ 环形饼图（岗位分布）/ 柱图（起薪对比）/ 柱线组合图（调研结果）

✓ TailwindCSS + 自定义主题

brand-600 = #165DFF 科技蓝主色调，玻璃态导航、渐变卡片、悬停动效

✓ 完整数据可视化流程

数据源选取 → 数据采集 → 数据清洗 → 统计建模 → 可视化呈现，5 步全流程

✓ 移动端响应式适配

TailwindCSS breakpoint，移动端汉堡菜单，图表自适应 resize

✓ 跨页面导航高亮

shared.js 统一 initNavbar()，当前页自动高亮，无需每个页面重复写
